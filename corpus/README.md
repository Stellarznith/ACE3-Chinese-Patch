# corpus —— 译文源

本目录存放**译文唯一来源**。镜像里的文本由这里的表格生成，不接受直接改镜像。

## 约定

- 每张表对应一个文本域（剧情 / 菜单 / 战斗 / 简报 / 辞典 …）。
- 列固定：`id`、`原文`、`译文`、`备注`。**不要改列名、不要改分隔符。**
- 编码 UTF-8（无 BOM），换行 LF。
- 空译文表示"保留原文"，不是"还没翻"；未翻译的条目写 `TODO:` 前缀。
