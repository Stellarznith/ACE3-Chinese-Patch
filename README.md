## 一、版本说明

**首个正式公开版本 · 持续完善中**

本项目是经过长期制作与调试、正式向玩家公开分享的汉化作品，不是临时测试包。发布时不使用「Beta」「公开测试版」「最终完美版」这类标签：它既不是内部半成品，也不宣称已经做到完美。

正式发布只代表「达到可以公开分享的完成度」，不代表零 Bug，也不代表全部流程都已经验证。当前已知限制包括：

- 部分贴图仍未汉化，保留原版日文或英文；
- 明亮战斗背景下，部分汉字边缘可能出现轻微灰线；
- 可能存在错译、漏译或文字显示异常；
- 真实 PS2 实机尚未验证。

真诚邀请各位玩家测试并反馈问题，后续会持续修复和更新。版本号规划：首个公开发行版本使用 `v1.0.0`，后续修复更新至 `v1.0.1` 等。

## 二、汉化完成度与测试状态

- **游戏文本：已完成全文本中文化**，包括剧情对白、系统菜单、战斗文本、人物及机体资料等。
- **游戏贴图：部分中文化**，仍有部分贴图保留原版日文或英文。
- **补丁还原：已通过验证。** 用随包发行的 xdelta3 3.2.2 从原版 ISO 还原，两条独立解码路径产出的镜像与汉化成品盘逐字节一致（差异 0 字节），原版 ISO 在操作前后的 SHA-256 与修改时间均未变化。
- **安装器：已在开发机上完成实测**（引擎直调与 GUI 全路径两条），覆盖补丁清单校验、原版指纹校验、`.part` 临时文件与不覆盖提交、取消与错误路径。**尚未在干净的 Windows 机器上做双击 EXE 的验证。**
- **模拟器测试**：具体兼容性与已知问题见[兼容性](docs/COMPATIBILITY.md)与[已知问题](docs/KNOWN_ISSUES.md)。
- **PS2 实机测试：尚未进行。** 目前无法保证汉化补丁在真实 PlayStation 2 主机上完全正常运行。

受原游戏字库容量、文本存储空间及界面显示等技术限制，部分中文译文可能存在表达略显生硬、不够自然的情况，希望大家理解。

虽然已经进行了大量汉化、审校和调试工作，但仍可能存在错译、漏译、文字显示异常、贴图问题、游戏卡死或其他尚未发现的 Bug。

## 四、下载

正式版本以 GitHub Releases 形式提供，首发包包含：

- 汉化补丁 `ACE3_CN_v1.0.0_full.xdelta`（差分文件，由日版原版 ISO 生成）
- 补丁清单 `ACE3_CN_v1.0.0_full.json`（安装器据此校验原版与成品指纹）
- Windows 图形化安装器 `ACE3_CN_Patcher.zip`（解压即用，内含 xdelta3）
- ACE3 汉化工坊 v1.0.4 可执行发行包 `ACE3_Workshop_v1.0.4.zip`（留档与核对用，v1.0.0 阶段不能独立运行，见下）
- xdelta3 命令行工具 `xdelta3.exe` / `xdelta3decode.exe`（供手动打补丁与自检）
- 发行记录 `patch_manifest.json`（构建方式、差异审计、还原验证的完整记录）
- `LICENSE-xdelta3.txt` / `NOTICE-xdelta3.txt`（第三方工具的许可与来源）
- `SHA256SUMS.txt` 校验清单
- 使用说明 `ACE3_CN_v1.0.0_readme.txt`（附件标签为「使用说明.txt」）

`SHA256SUMS.txt` 覆盖上述 8 个散件与 2 个发行包 ZIP，共 10 条，不含它自身。

工坊发行包内含 `ACE3汉化工坊.exe`（5,776,792 字节，MD5 `9a65e1645ae992f4bc9e221dc15a3c74`）、`_internal/` 运行时依赖与 `LICENSES/` 第三方许可目录，共 205 个文件。它运行时需要读取汉化工程内部的只读数据（索引库、码表、字体缓存），这部分 v1.0.0 暂不公开，所以**下载后不能直接使用**；提供它是为了留档与核对，程序本体、依赖与许可均可验证，源码在[汉化工坊源码](workshop/)。

发布包内容与校验值以 Release 页面为准；本仓库不提交补丁与安装器二进制。每次发布时，Release 说明按[发布说明模板](docs/RELEASE_TEMPLATE.md)填写。

## 五、安装

1. 自备**日版原版 ISO**，先记录其 SHA-256。
2. 安装器会校验原版指纹，不匹配则拒绝安装；也可以手动用 xdelta 打补丁。
3. 输出到新文件，原版 ISO 不会被覆盖。

详细步骤、常见错误与手动命令行写法见[安装说明](docs/INSTALL.md)。

后续版本计划提供**完整补丁**（由原版生成成品）与**增量补丁**（旧版升级到新版）两种，安装器通过补丁清单识别类型与适用镜像；v1.0.0 只提供完整补丁，增量补丁要等真实生成并验证后才会发布。

## 六、原版游戏要求
