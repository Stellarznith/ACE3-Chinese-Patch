## 三、安装

1. 自备**日版原版 ISO**，先记录其 SHA-256。
2. 安装器会校验原版指纹，不匹配则拒绝安装；也可以手动用 xdelta 打补丁。
3. 输出到新文件，原版 ISO 不会被覆盖。

详细步骤、常见错误与手动命令行写法见 [安装说明](docs/INSTALL.md)。

## 五、汉化质量与翻译限制

受原游戏字库容量、文本空间及界面显示等技术条件限制，个别译文可能存在表达略显生硬、不够自然或与理想译法有所差异的情况。制作过程中已尽可能兼顾原文含义、中文表达与游戏内实际显示效果。

由于个人能力和测试条件有限，汉化补丁也可能存在错译、漏译、文字显示异常或其他尚未发现的问题。如果在游玩中发现翻译错误、显示问题或程序 Bug，欢迎通过 GitHub Issues 反馈，合理的反馈将有助于后续版本持续完善。

本项目的翻译与工程工作借助 AI 助手参与执行与核对，最终内容由作者确认。已知问题见 [已知问题](docs/KNOWN_ISSUES.md)，验证范围见 [验证记录](docs/VERIFICATION.md)。
