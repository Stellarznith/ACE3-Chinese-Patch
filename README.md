## 一、这个仓库有哪些东西，没有哪些东西

| | 内容 |
|---|---|
| **有** | 汉化构建脚本、译文源文件、字库与映射表、校验清单、工程文档 |
| **有（发布后）** | 对日版原盘的差分补丁（`.xdelta`）、补丁校验值、安装与恢复说明 |

本仓库不提供、也不会提供让游戏"能跑起来"所需的任何本体数据。

## 三、使用方式（发布后生效）

1. 准备日版原盘 `SLPS-25784` 的 ISO 或镜像文件，先记下它的 SHA-256 / MD5。
2. 下载 Release 里的差分补丁与 `SHA256SUMS.txt`，核对补丁自身的校验值。
3. 对原盘打补丁，得到汉化镜像：

   ```bash
   xdelta3 -d -s original.iso ace3-zh-<版本>.xdelta ace3-zh-<版本>.iso
   ```

4. 用 PCSX2 载入汉化镜像。**建议先备份原盘与记忆卡**。

原盘身份、补丁产物与前后校验值，统一记在 [复现说明](REPRODUCE.md) 与 `manifests/` 下。

> 请注意：每个补丁只对应**一个**原盘版本。请不要在旧汉化版、整合版或其他地区的镜像上重复打补丁。

## 四、适配范围与限制

- 仅适配日版 **SLPS-25784**。其他地区版本、廉价版、修改版镜像不在支持范围。
- 存档：汉化不改变存档结构，但**不保证**与日版存档互相兼容；跨版本回退前请备份记忆卡。
- 模拟器：以 PCSX2 为主要验证环境。实机（PS2 + 硬盘/FMCB）尚未验证，不承诺可用。
- 已完成的验证只覆盖列出的屏幕与流程；**未做全路线通关验收，也不承诺修复所有卡死、黑屏或花屏**。
- 部分专有名词、缩写、版权署名与装饰文字可能保留原文。

## 五、从源码复现

构建需要 Python 3.10+、xdelta3，以及你自己合法持有的日版原盘。
逐条命令、每步的输入输出校验值与失败判据见 [复现说明](REPRODUCE.md)；
环境与依赖锁定见 [构建与复现](docs/01-构建与复现.md)。

```bash
python3 scripts/build_release.py --source /path/to/original.iso --out build/
```

脚本只读原盘、只写 `build/`，不会修改任何输入文件。所有改动都必须来自可重跑的脚本，
不接受"手工改 ISO"式的不可追溯修改——这是本项目的硬约束。
