## 一、汉化完成度与测试状态

- **游戏文本：已完成全文本中文化**，包括剧情对白、系统菜单、战斗文本、人物及机体资料等。
- **游戏贴图：部分中文化**，仍有部分贴图保留原版日文或英文。
- **模拟器测试**：以实际完成的测试结果为准，具体兼容性与已知问题将在后续持续更新，见[兼容性](docs/COMPATIBILITY.md)与[已知问题](docs/KNOWN_ISSUES.md)。
- **PS2 实机测试：尚未进行。** 目前无法保证汉化补丁在真实 PlayStation 2 主机上完全正常运行。

受原游戏字库容量、文本存储空间及界面显示等技术限制，部分中文译文可能存在表达略显生硬、不够自然的情况，希望大家理解。

虽然已经进行了大量汉化、审校和调试工作，但仍可能存在错译、漏译、文字显示异常、贴图问题、游戏卡死或其他尚未发现的 Bug。

本项目的翻译与工程工作借助 AI 助手参与执行与核对，最终内容由作者确认。

## 二、欢迎参与测试与反馈

本项目由个人独立制作和维护，能够覆盖的测试环境及游戏流程有限，因此非常欢迎各位玩家一起参与测试！

无论使用 PCSX2 模拟器还是 PlayStation 2 实机，如果发现任何问题，都欢迎通过 GitHub Issues 反馈。

反馈时请尽可能提供：

1. **问题类型**：翻译错误、显示异常、贴图问题、黑屏、卡死等。
2. **出现位置**：关卡、剧情、菜单或其他具体场景。
3. **复现方式**：进入该场景前进行了哪些操作。
4. **运行环境**：PCSX2 版本及关键设置，或 PS2 实机型号及运行方式。
5. **截图或日志**：尽可能附上问题截图与相关信息。

请勿上传或分享完整游戏 ISO、BIOS 等受版权保护的文件。

如果条件允许，反馈游戏 Bug 时还可以附上问题发生时的 **PCSX2 GS Dump** 与**即时存档**，能更快复现和定位问题；这两项是推荐项，不是必须。这类文件可能包含游戏资源数据，请勿直接公开上传大型文件，先开 Issue 与维护者确认提供方式。详见[参与与反馈](CONTRIBUTING.md)。

对于收到的有效反馈，我会尽可能在后续版本中进行修复和完善。

感谢每一位愿意体验、测试和帮助完善本项目的玩家！

## 三、下载

尚未发布。正式版本会以 GitHub Releases 形式提供：

- 汉化补丁（差分文件，`ACE3_CN_v<版本>.xdelta`）
- Windows 图形化安装器（`ACE3_CN_Patcher.exe`）
- `SHA256SUMS.txt` 校验清单

发布包内容与校验值以 Release 页面为准；本仓库不提交补丁与安装器二进制。每次发布时，Release 说明按[发布说明模板](docs/RELEASE_TEMPLATE.md)填写。

## 四、安装

1. 自备**日版原版 ISO**，先记录其 SHA-256。
2. 安装器会校验原版指纹，不匹配则拒绝安装；也可以手动用 xdelta 打补丁。
3. 输出到新文件，原版 ISO 不会被覆盖。

详细步骤、常见错误与手动命令行写法见[安装说明](docs/INSTALL.md)。

后续版本计划提供**完整补丁**（由原版生成成品）与**增量补丁**（旧版升级到新版）两种，安装器通过补丁清单识别类型与适用镜像；这两种补丁的机制见安装说明，实际增量补丁要等真实生成并验证后才会发布。
