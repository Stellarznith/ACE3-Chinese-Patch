# 常见问题

## 这个汉化收费吗？

不收费，永久免费。欢迎免费转载，但禁止转卖或付费下载，见 [转载与分发政策](../DISTRIBUTION.md)。

## 需要什么才能用？

日版原版 ISO（SLPS-25784）加本补丁。项目不提供游戏本体，也不提供下载渠道。

## 能用在美版、欧版或其他版本上吗？

不能。不同版本的数据结构与文本位置不同，安装器会拒绝指纹不匹配的镜像。

## 打补丁会覆盖我的原版 ISO 吗？

不会。安装器输出新文件，原版保持不变。

## 补丁有多大？

取决于与成品的差异量，具体数值在 Release 页面公布。补丁体量不等于汉化工作量。

## 中文存档和日文存档能互通吗？

待定。存档格式未做改动，但因文本编码变化，跨版本读档可能显示异常。建议不要混用，正式结论以实测为准。

## 为什么不做"整合版 ISO"？

分发完整游戏镜像涉及游戏本体的版权，本项目只提供补丁。

## 我能把补丁放进自己的整合包或网盘吗？

可以免费转载、镜像，但不得收费，也不得把完整游戏与补丁捆绑分发。修改后再发布需明确说明与官方版本的区别。

## 发现翻译错误怎么办？

用 Issue 模板反馈，见 [参与与反馈](../CONTRIBUTING.md)。受字库容量与显示宽度限制，部分建议可能无法落地。

## 为什么有些句子读起来不自然？

原游戏字库容量与文本空间有限，部分译文需要在字数与语感之间取舍，见 README 的"汉化质量与翻译限制"。

## 支持实机（PS2 + 硬盘/刻盘）吗？

待定。当前以 PCSX2 为主要测试环境，实机验证结果会在 [兼容性](COMPATIBILITY.md) 更新。
