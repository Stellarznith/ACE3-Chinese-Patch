## 本版内容

- 全文本中文化：剧情对白、系统菜单、战斗文本、人物及机体资料。
- 统一字库与码表，修正字距与字形渲染（含文字边缘灰线的条件化处理）。
- 部分界面贴图中文化，其余保留原版日文或英文。
- 提供 Windows 图形化安装器，自动校验原版指纹、拒绝错误版本、不覆盖原版文件。
- 公开打补丁工具与汉化工坊源码（MIT）。

## 安装方法

1. 准备日版原版 ISO，记录其 SHA-256。
2. 解压 `ACE3_CN_Patcher.zip`，把 `.xdelta`、同名 `.json` 与 `xdelta3.exe` 放在同一目录，运行 `ACE3_CN_Patcher.exe`。
3. 依次选择补丁、原版 ISO、输出路径。安装器校验原版指纹，通过后生成汉化版 ISO；原版不被覆盖，已有文件不被覆盖。
4. 用 PCSX2 或实机载入生成的 ISO。

手动安装：

```powershell
xdelta3 -d -f -s "SLPS-25784.iso" "ACE3_CN_v1.0.0_full.xdelta" "ACE3_CN_v1.0.0.iso"
Get-FileHash -Algorithm SHA256 "ACE3_CN_v1.0.0.iso"
```

结果应为 `368f4a7f6c5dafcb14d822d8fb3a44585c1ab23a32bfad11d84b2eea1635bc12`。

详细步骤与排错见仓库 `docs/INSTALL.md`。
