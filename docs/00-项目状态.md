1. 只适配日版 SLPS-25784；其他版本不支持。
2. 实机（PS2 本体 + 硬盘/FMCB）**未验证**。
3. 未做全路线通关；低频分支、特定任务组合可能仍有未发现的问题。

5. 存档兼容性未做系统性测试，回退版本前必须备份记忆卡。

## 六、口径约定

对外报数必须带四要素：**统计对象 / 工具版本 / 盘 MD5 / 完整命令**。
缺一项的数字不得写进发布文档，也不得作为验收依据。

历史上曾出现同一问题报出四个互相矛盾的数字，全部源于口径不一致。
这条约定就是为了杜绝它再次发生。
