## 写作约定

1. **区分"验过"和"没验过"**。没有实机/模拟器验证记录的结论，必须标 `未验证`。
2. **数字要能追**。任何数量（缺字数、字符数、容量、哈希）必须写明来源与统计口径。
3. **不写"应该没问题"**。不确定就写不确定，并说明卡在哪。
4. **作废的结论要撤销**，不要留在文档里让人误读；迁移到内部工程史，不留在发布文档。
