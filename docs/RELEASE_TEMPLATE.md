> 增量补丁只有在真实生成并验证通过后才会发布；未生成时，Release 说明中不出现 Update 包，也不宣称增量更新可用。

## 安装方法

1. 准备日版原版 ISO，记录其 SHA-256。
2. 解压安装器，把 `.xdelta`、`.json` 与 `xdelta3.exe` 放在同一目录，运行 `ACE3_CN_Patcher.exe`。
3. 选择补丁与原版 ISO，再选输出路径；安装器校验通过后生成汉化版 ISO，原版不被覆盖。
4. 用模拟器或实机载入生成的 ISO。

手动方式与排错见仓库 `docs/INSTALL.md`。
