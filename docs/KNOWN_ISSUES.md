## 已知限制（不是缺陷，但会影响体验）

以下几条属于当前版本的客观限制，不是待修复的 Bug，先写在这里避免玩家误解：

- **图内文字未全部中文化**：部分贴图仍保留原版日文或英文，属于贴图工作量尚未完成，不是显示错误。
- **明亮背景下汉字边缘可能有轻微灰线**：文字渲染在明亮战斗背景（尤其 6x 内部分辨率）下，部分汉字边缘可见淡灰色描边。已做过条件化处理，绝大部分场景明显改善，但未彻底消除。
- **PS2 实机未测试**：目前只在模拟器环境下验证；实机能否正常运行（尤其是刻录盘、硬盘引导等运行方式）尚无结论。
- **安装器未在干净机器上验证**：安装器在开发机上完成了引擎直调与 GUI 全路径实测，尚未在全新安装的 Windows 上双击 EXE 验证。
- **个别译文不够自然**：受原游戏字库容量、文本存储空间与界面显示区域限制，部分句子只能压缩或改写，读起来可能略显生硬。
- **可能存在未发现的问题**：错译、漏译、文字显示异常、贴图错位、黑屏、卡死等情况无法完全排除。

## 分类

- **显示**：缺字、错字、文字溢出、贴图错位。
- **功能**：黑屏、死机、读档失败。
- **翻译**：错译、漏译、术语不一致。
- **安装**：校验失败、路径问题、空间不足。

## 反馈

发现问题时请通过 GitHub Issues 提交，并附上问题类型、出现位置、复现步骤、运行环境（PCSX2 版本与关键设置，或实机型号与运行方式）以及截图或日志。请勿上传完整游戏 ISO、BIOS 等受版权保护的文件。
