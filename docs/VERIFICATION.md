# 验证记录

本项目统一区分两类运行环境：**PCSX2 模拟器**与**真实 PS2 主机**。两者的结论不可互相代替，「模拟器能跑」不等于「实机已验证」。

## 二、验证口径

- **静态**：文件存在、格式正确、哈希匹配。
- **离线**：补丁还原后与成品母盘逐字节一致。
- **安装器**：正常路径、中文路径、空间不足、错误版本、损坏补丁五类用例。
- **PCSX2 模拟器**：由用户在模拟器下按[测试清单](TEST_REPORT.md)执行，记录 PCSX2 版本与关键设置。
- **真实 PS2 主机**：需在实机上运行，记录主机型号与运行方式（刻录盘、硬盘引导等）；目前**尚未进行**。
- **最终验收**：由用户负责，依据实际游玩结果给出结论；协助者不代填、不推断。

## 三、v1.0.0 补丁还原验证（离线，已完成）

对象：日版原版 ISO → 汉化成品 ISO，用发行包内 xdelta3 3.2.2 解码。

| 判据 | 结果 |
|---|---|
| 还原产物大小 = 成品大小（4,447,076,352） | 一致 |
| 还原产物 MD5 = `47a9c9e3c18a823ef311ff7ea8150577` | 一致 |
| 还原产物 SHA-256 = `368f4a7f…1635bc12` | 一致 |
| 还原产物与成品母盘逐字节比较 | 差异 0 字节 |
| 原版 ISO 在操作前后的 SHA-256 | 未变 |
| 防呆项：原版与还原产物的差异字节数 | 669,741,248（非零，确认补丁确实被应用） |

两条独立路径：`xdelta3.exe`（引擎内调用）与 `xdelta3decode.exe`（只解码构建），产物互相一致。安装器引擎直调 6 项判据全过；GUI 全路径 14 项判据全过（含成功弹框、按钮复位、无残留 `.part`）。

**边界**：以上均为开发机上完成的离线与本地验证，不等于干净 Windows 机器上双击 EXE 的验证，也不代表游戏运行已验收。

每条记录写清：日期、环境（构建 / Windows / PCSX2 / 真实 PS2）、验证对象（含哈希）、方法、结果、证据位置。

```

```
