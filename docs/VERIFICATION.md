# 验证记录

本页记录「做过什么验证、结果如何」。**没有证据的条目不填「通过」。**

本项目统一区分两类运行环境：**PCSX2 模拟器**与**真实 PS2 主机**。两者的结论不可互相代替，「模拟器能跑」不等于「实机已验证」。

## 二、验证口径

- **静态**：文件存在、格式正确、哈希匹配。
- **离线**：补丁还原后与成品母盘逐字节一致。
- **安装器**：正常路径、中文路径、空间不足、错误版本、损坏补丁五类用例。
- **PCSX2 模拟器**：由用户在模拟器下按[测试清单](TEST_REPORT.md)执行，记录 PCSX2 版本与关键设置。
- **真实 PS2 主机**：需在实机上运行，记录主机型号与运行方式（刻录盘、硬盘引导等）；目前**尚未进行**。
- **最终验收**：由用户负责，依据实际游玩结果给出结论；协助者不代填、不推断。

## 三、记录格式

每条记录写清：日期、环境（构建 / Windows / PCSX2 / 真实 PS2）、验证对象（含哈希）、方法、结果、证据位置。

```
2026-XX-XX | PCSX2 | 补丁还原 | 原版 <hash> → 成品 <hash> | xdelta -d 后逐字节比对 | 一致
```

## 四、不得写入的内容

- 未实际执行的测试。
- 用户尚未反馈的结论。
- 把 PCSX2 的结果写成真实 PS2 主机的结果，或反过来。
- 未经实测的存档兼容性解释。
- 推测的覆盖率或「应该没问题」的判断。
