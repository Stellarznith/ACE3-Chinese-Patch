## 二、验证口径

- **静态**：文件存在、格式正确、哈希匹配。
- **离线**：补丁还原后与成品母盘逐字节一致。
- **安装器**：正常路径、中文路径、空间不足、错误版本、损坏补丁五类用例。
- **实机**：由用户在 PCSX2 下按 [测试清单](TEST_REPORT.md) 执行。

## 三、记录格式

每条记录写清：日期、验证对象（含哈希）、方法、结果、证据位置。

```
2026-XX-XX | 补丁还原 | 原版 <hash> → 成品 <hash> | xdelta -d 后逐字节比对 | 一致
```

## 四、不得写入的内容

- 未实际执行的测试。
- 用户尚未反馈的实机结论。
- 推测的覆盖率或"应该没问题"的判断。
