# 安装说明

> 状态：安装器尚未实现，本页先固定玩家流程与判据。命令与提示文本可能随实现调整。

## 一、准备

1. **日版原版 ISO**（SLPS-25784）。请自行确认来源合法。
2. 至少 5 GB 可用磁盘空间（输出为完整镜像副本，不覆盖原文件）。
3. 记录原版 ISO 的 SHA-256：

```powershell
Get-FileHash -Algorithm SHA256 "D:\path\to\SLPS-25784.iso"
```

## 二、图形界面安装（推荐）

1. 运行 `ACE3_CN_Patcher.exe`。
2. 选择原版 ISO；安装器读取 SHA-256 并与预期指纹比对。
   - 匹配：继续。
   - 不匹配：停止，并提示"版本不受支持"。不要强行继续。
3. 选择输出位置与文件名。**不要**选原版 ISO 本身。
4. 开始安装。安装器写入新文件，完成后校验成品 SHA-256。
5. 显示成功与成品哈希；失败时保留日志并给出原因。

## 三、手动安装（xdelta3）

```powershell
xdelta3 -d -s "SLPS-25784.iso" "ACE3_CN_v1.0.0.xdelta" "ACE3_CN_v1.0.0.iso"
Get-FileHash -Algorithm SHA256 "ACE3_CN_v1.0.0.iso"
```

把结果与 Release 页面给出的成品 SHA-256 对照，一致才算安装成功。

## 四、运行

用 PCSX2 载入成品 ISO。建议先跑一遍标题、主菜单与一段对话，确认文字正常再继续游戏。

## 五、常见失败原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示版本不受支持 | 原版不是 SLPS-25784，或镜像被改动过 | 换回未修改的日版原版 |
| 补丁应用失败 | 补丁文件损坏，或用了错误的源镜像 | 重新下载补丁，核对 SHA-256 |
| 输出文件比预期小 | 磁盘空间不足 | 清理空间后重试 |
| 打完补丁黑屏 | 成品校验不通过，或模拟器设置问题 | 先核对成品哈希，再检查模拟器 |
| 中文路径报错 | 安装器的路径处理缺陷 | 记录路径并反馈，见 [反馈](../CONTRIBUTING.md) |
