# 安装说明

> 状态：安装器已实现并在开发机上完成实测；补丁已生成并通过还原验证。v1.0.0 只提供**完整补丁**（由日版原版生成汉化成品），暂不提供增量补丁。

## 一、准备

1. **日版原版 ISO**（SLPS-25784）。请自行确认来源合法。
2. 至少 5 GB 可用磁盘空间（输出为完整镜像副本，不覆盖原文件）。
3. 记录原版 ISO 的 SHA-256，用于和下面的指纹对照：

```powershell
Get-FileHash -Algorithm SHA256 "D:\path\to\SLPS-25784.iso"
```

正确的原版应为 4,447,076,352 字节，SHA-256 `5264079d36d953f464b166052e1ddea9be22a84c30a9333da24b8e1471311705`。大小或哈希不符，说明镜像不是这一版或已被改动，补丁会拒绝安装。

## 二、图形界面安装（推荐）

1. 解压 `ACE3_CN_Patcher.zip`，运行其中的 `ACE3_CN_Patcher.exe`。补丁文件 `.xdelta`、同名清单 `.json` 与 `xdelta3.exe` 需要放在**同一个目录**里。
2. 选择补丁 `.xdelta`。安装器自动读取同目录、同文件名的 `.json` 清单。
3. 选择原版 ISO。安装器计算其 SHA-256 并与清单中的 `source.iso_sha256` 比对：
   - 匹配：继续。
   - 不匹配：停止并提示不受支持。**不提供强制继续**，请换回未修改的日版原版。
4. 选择输出位置与文件名。**不要**选原版 ISO 本身，也不要选已存在的文件（安装器不覆盖已有文件）。
5. 开始安装。还原结果先写入输出文件旁的 `.part` 临时文件，校验大小与 SHA-256 通过后才提交为正式文件。
6. 成功后显示成品哈希；失败时给出原因，且不会留下被误认为成品的文件。

三个「浏览…」按钮各自记住上次打开的目录（补丁、输入 ISO、输出 ISO 互不影响），记忆写在 `%LOCALAPPDATA%\ACE3_CN_Patcher\settings.json`。目录被删除或改名后会自动退回默认位置。

## 三、手动安装（xdelta3）

发行包内附带经核验的 xdelta3 3.2.2：

```powershell
xdelta3 -d -f -s "SLPS-25784.iso" "ACE3_CN_v1.0.0_full.xdelta" "ACE3_CN_v1.0.0.iso"
Get-FileHash -Algorithm SHA256 "ACE3_CN_v1.0.0.iso"
```

把结果与第七节的成品 SHA-256 对照，一致才算安装成功。`xdelta3decode.exe` 是同一上游的只解码构建，可作第二条独立路径交叉验证。

## 四、补丁清单机制

安装器不靠文件名猜测补丁用途，而是读取补丁旁的 JSON 清单。v1 协议的字段是冻结的：

| 字段 | 说明 |
|---|---|
| `schema_version` | 固定为整数 `1`；其它值一律拒绝 |
| `patch_type` | `FULL` 或 `UPDATE`，仅作展示，兼容性由 `source` 的精确大小与 SHA-256 决定 |
| `source.version` | 输入镜像的版本标签（给人看） |
| `source.iso_size_bytes` | 输入镜像的精确字节数 |
| `source.iso_sha256` | 输入镜像的 SHA-256 |
| `target.version` | 输出镜像的版本标签 |
| `target.iso_size_bytes` | 输出镜像的精确字节数 |
| `target.iso_sha256` | 输出镜像的 SHA-256 |
| `patch.filename` | 补丁文件名，必须与磁盘上的 basename 精确一致 |
| `patch.size_bytes` | 补丁精确字节数 |
| `patch.sha256` | 补丁 SHA-256 |
| `patch.format` | v1 固定为 `xdelta3` |
| `patch.format_version` | 生成补丁所用的编码器版本，仅描述性，不表示格式兼容性 |

安装器严格拒绝未知 schema 版本与未知字段。协议语义详见 `installer/release_manifest_protocol.md`，Schema 见 `installer/release_manifest.schema.json`。

| 类型 | 用途 | v1.0.0 状态 |
|---|---|---|
| Full 完整补丁 | 由日版原版 ISO 生成完整汉化版 ISO | 已提供并验证 |
| Update 增量补丁 | 在已安装旧版汉化版的基础上升级到新版 | 尚未提供 |

## 五、运行

用 PCSX2 载入成品 ISO。建议先跑一遍标题、主菜单与一段对话，确认文字正常再继续游戏。真实 PS2 主机目前**尚未测试**，实机运行方式（刻录盘、硬盘引导等）请自行评估。

## 六、常见失败原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示版本不受支持 | 原版不是 SLPS-25784，或镜像被改动过 | 换回未修改的日版原版 |
| 提示补丁指纹不符 | 补丁文件损坏或下载不完整 | 重新下载，与 `SHA256SUMS.txt` 对照 |
| 提示找不到清单 | `.json` 与 `.xdelta` 不在同一目录或文件名主体不同 | 两者放回同一目录，保持同名 |
| 输出文件比预期小 | 磁盘空间不足 | 清理空间后重试 |
| 提示目标已存在 | 输出路径指向了已存在的文件 | 换一个文件名；安装器不覆盖 |
| 打完补丁黑屏 | 成品校验不通过，或模拟器设置问题 | 先核对成品哈希，再检查模拟器 |
| 中文路径相关报错 | 安装器的路径处理缺陷 | 记录完整路径并反馈，见[反馈](../CONTRIBUTING.md) |

安装成功只证明输出与所选清单里的目标指纹相符，**不代表** PCSX2 或实际游戏运行已通过测试。
