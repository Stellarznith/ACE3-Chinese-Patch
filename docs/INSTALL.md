# 安装说明

> 状态：安装器尚未实现，本页先固定玩家流程、判据与补丁清单机制。命令与提示文本可能随实现调整。

## 一、准备

1. **日版原版 ISO**（SLPS-25784）。请自行确认来源合法。
2. 至少 5 GB 可用磁盘空间（输出为完整镜像副本，不覆盖原文件）。
3. 记录原版 ISO 的 SHA-256：

```powershell
Get-FileHash -Algorithm SHA256 "D:\path\to\SLPS-25784.iso"
```

## 二、图形界面安装（推荐）

1. 运行 `ACE3_CN_Patcher.exe`。
2. 选择原版 ISO；安装器读取 SHA-256 并与补丁清单中的预期指纹比对。
   - 匹配：继续。
   - 不匹配：停止，并提示「版本不受支持」。不要强行继续。
3. 选择输出位置与文件名。**不要**选原版 ISO 本身。
4. 开始安装。安装器写入新文件，完成后校验成品 SHA-256。
5. 显示成功与成品哈希；失败时保留日志并给出原因。

## 三、手动安装（xdelta3）

```powershell
xdelta3 -d -s "SLPS-25784.iso" "ACE3_CN_v1.0.0.xdelta" "ACE3_CN_v1.0.0.iso"
Get-FileHash -Algorithm SHA256 "ACE3_CN_v1.0.0.iso"
```

把结果与 Release 页面给出的成品 SHA-256 对照，一致才算安装成功。

## 四、补丁类型与清单（机制预留）

后续版本计划提供两种补丁，安装器通过**统一的补丁清单**识别类型与适用范围，而不是靠文件名猜测：

| 类型 | 用途 | 当前状态 |
|---|---|---|
| Full 完整补丁 | 由日版原版 ISO 生成完整汉化版 ISO | 尚未提供 |
| Update 增量补丁 | 在已安装旧版汉化版的基础上升级到新版 | 尚未提供 |

清单字段（拟定）：

| 字段 | 说明 |
|---|---|
| `patch_type` | `full` 或 `update` |
| `target_version` | 打完补丁后的版本号 |
| `source_version` | 增量补丁的起始版本（Full 补丁为空） |
| `source_sha256` | 允许的输入镜像哈希（Full 补丁为原版 ISO） |
| `result_sha256` | 打完后应得到的镜像哈希 |
| `patch_sha256` | 补丁文件自身的哈希 |

安装器先读清单，再决定「这个补丁能不能用在当前选择的镜像上」；不匹配就拒绝，不提供强制继续。

> 以上是机制设计。**真实补丁生成前，不提供任何增量补丁，也不在 Release 中宣称增量更新可用。**

## 五、运行

用 PCSX2 载入成品 ISO。建议先跑一遍标题、主菜单与一段对话，确认文字正常再继续游戏。真实 PS2 主机目前**尚未测试**，实机运行方式（刻录盘、硬盘引导等）请自行评估。

## 六、常见失败原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示版本不受支持 | 原版不是 SLPS-25784，或镜像被改动过 | 换回未修改的日版原版 |
| 补丁应用失败 | 补丁文件损坏，或用了错误的源镜像 | 重新下载补丁，核对 SHA-256 |
| 输出文件比预期小 | 磁盘空间不足 | 清理空间后重试 |
| 打完补丁黑屏 | 成品校验不通过，或模拟器设置问题 | 先核对成品哈希，再检查模拟器 |
| 中文路径报错 | 安装器的路径处理缺陷 | 记录路径并反馈，见[反馈](../CONTRIBUTING.md) |

## 七、输出与指纹

| 对象 | SHA-256 |
|---|---|
| 日版原版 ISO | 待定 |
