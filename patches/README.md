# patches —— 差分补丁产物

本目录**不存放**补丁文件，只存放说明与指向。

补丁（`.xdelta`）通过 GitHub Releases 分发，原因：

1. 单文件体积超出仓库合理范围；
2. Release 资产可以单独记录下载量、单独撤回；
3. 避免仓库被大文件撑爆导致 clone 困难。

## 命名

```text
ace3-zh-<主>.<次>.<修订>.xdelta
```

## 每个补丁必须配套

- `SHA256SUMS.txt`：补丁自身与成品镜像的校验值
- `安装说明.txt`：核对原盘 → 打补丁 → 校验成品

## 关于"能不能直接发 ISO"

不能。补丁只包含"相对原盘的差异"，不含游戏本体；直接发镜像等于分发游戏，超出本项目范围。
